# Aborted broad Q2_0 API attempt

The initial seven-pair, two-cell API campaign was stopped during the first
candidate process after its distinct 512/64 warmup passed and the 2,048-token
warmup began. No measured baseline/candidate pair was completed, so this
directory contains no performance inference. The candidate process retained
the six-GiB physical-memory floor; it was stopped to narrow the next run to a
single short output cell while confirming the end-to-end dispatch route.

The three-pair Q2_0 512/8 screen is recorded separately under
`2026-10-13-phase4-q8_1-neon-q2-api-screen3/`.
