# Current-source near-limit accepted-prefix runtime check — Orin — 2026-10-14

This extends the current-source accepted-only MTP state check to a 7,498-token
formatted synthetic prompt at the 8,192-token context limit. It compares MTP
off with window 4 on the current native CUDA/ARM64 binary. The exact rendered
prompt is generated by `accepted_prefix_parity.py`'s independent-length prompt
helper and identified by the prompt hash in `run/results.json`.

The Q2_0 model, PLE pack and MTP pack remain under
`~/models/strata-orin-validation/`. Both services used FP16 KV, 3,000 actual
expert slots, prefill 512, an 8,192 context, a 3-GiB workspace reserve, CPU
prefill sharing disabled and 32 output tokens. MTP4 accepted 18 of 30 drafts.
The token IDs matched exactly; all nine persistent main-model state fields
matched at final state and all 14 shared accepted-prefix boundaries.

The 28-GiB supervised run completed in 268.26 seconds. Minimum physical host
and admission availability was 16.98 and 13.80 GiB. Sampled cgroup
`low`/`high`/`max`/OOM counters stayed at zero. This verifies state parity for
one synthetic near-limit prompt and the recorded configuration. It is not a
long-context retrieval-quality result, a recovery-after-swap result or a
performance comparison.

Reproduce from the repository root:

```sh
systemd-run --user --scope --collect -p MemoryMax=28G -p IOAccounting=yes \
  python3 tools/integration/run_control.py \
  --output bench/results/2026-10-14-phase5-current-source-long-runtime/supervisor \
  --timeout 7200 --interval 1 --sample-clocks -- \
  python3 tools/integration/accepted_prefix_parity.py \
  --config bench/results/2026-10-14-phase5-accepted-window-256/config.json \
  --engine build/integration/candidate/strata \
  --output bench/results/2026-10-14-phase5-current-source-long-runtime/run \
  --prompt-tokens 7498 --tokens 32 --windows 0 4 \
  --use-config-adaptive-swaps --run
```

Raw per-arm engine logs, comparison JSON and supervisor memory/clock samples
are retained here. `SHA256SUMS.txt` verifies the files.
