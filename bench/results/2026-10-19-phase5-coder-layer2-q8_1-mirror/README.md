# Coder layer-2 IQ4_NL Q8_1 mirror and service check — Orin — 2026-10-19

This diagnostic adds an opt-in scalar CPU mirror for the CUDA IQ4_NL down
projection when the expert's gate/up weights are IQ2_S. Setting
`STRATA_NATIVE_CPU_Q8_1_DOT=1` selects Q8_1 activation quantization for both
projections for the IQ2_S/Q2_0 and IQ2_S/IQ4_NL pairs. The default dispatch is
unchanged. The IQ4_NL scalar reduction follows the CUDA `native_small_mmvq`
block-to-lane assignment, per-thread accumulation, warp partial order and XOR
reduction. The existing Q2_0 mirror is unchanged.

The standalone checker passed synthetic token widths 1–8. On the captured
layer-2 Coder activation at verifier position 511/token 271, each of the seven
CPU-owned experts (174, 62, 69, 130, 143, 151, 28) passed all widths 1–8:
Q8_1 scale/code mismatches were 0/20 blocks and CPU/CUDA down-projection
output-word mismatches were 0/2,560 for each width and expert. Each expert
check ran in its own 28-GiB scope; minimum host/admission availability was
24.51 GiB and cgroup memory-event counters stayed at zero. The direct operator
reproduction is `run.sh`; raw logs and samples are in `supervisor-e*-confirm1/`.
On the current Orin build, the default IQ2_S/IQ4_NL synthetic parity test and
both opt-in Q8_1 tests (single-width and widths 1–8) passed through CTest.
Two earlier service-harness starts are retained as setup failures: the legacy
runner rejected the current capture-v3 header, then the copied runner used an
incorrect repository-root depth. Neither was counted as a service result; the
corrected v3 runner passed both matched pairs below.

The full-expert comparison is now informational; the isolated down projection
remains the exact assertion.

This exact down-projection result does not make the whole expert bitwise equal.
The full CPU/CUDA expert outputs retain a very small relative-L1 residual
(2.13e-8–2.78e-8 on these captured cases). Its source has not been isolated;
gate/up dot accumulation and backend-specific SwiGLU rounding remain possible
contributors.
The isolated check intentionally treats the down projection as the exact
contract and reports whole-expert comparison separately.

Clock sampling was observational with dynamic clocks; process energy was not
measured. These runs are functional diagnostics, not throughput or energy
comparisons, and the generated text is not an independent task-quality score.

The exact IQ4_NL dot mirror therefore does not restore complete persistent
state equivalence. It changes observable numerical behavior under this opt-in
route, so it remains diagnostic and no default or quality claim follows. These
two pairs do not identify a complete causal path between CPU/GPU migration and
continuation drift, and they do not qualify adaptive migration. Phases 5 and 6
remain open.
