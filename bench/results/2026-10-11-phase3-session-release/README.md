# Session backing teardown — Q2_0 Orin — 2026-10-11

The primary session arena, every split-stage arena, and batch-slot arenas now have explicit owners. The owners call `session_release` while the carved state is alive, select the owning device, free the backing, and emit matching trace events. Batch arenas are also released before their `SessionState` objects when admission trims slots or disables batching. Primary allocation tracing starts immediately after `cudaMalloc`, so a later `session_init` failure also has a matching allocation and cleanup.
