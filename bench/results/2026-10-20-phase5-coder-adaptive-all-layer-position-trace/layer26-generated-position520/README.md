# Generated position 520 adaptive trace — Orin — 2026-10-20

This randomized same-service pair used the pinned Coder IQ1_M model, current
candidate binary `9212d814…`, accepted-only adaptive accounting, and
`STRATA_NATIVE_CPU_Q8_1_DOT=all`. It compared cap-8 adaptation with delayed
adaptation through a 512→2,048→512 request sequence. Each recovery returned the
same 16 token IDs as its initial short request. The capture at absolute
position 520 retained per-layer MoE dispatch rows and layer-26 GDN verifier
intermediates for each initial/recovery request. It is a correctness diagnostic,
not a performance or quality comparison.

The delayed arm had no layer activation, expert-ID, or route-owner differences
and all captured layer-26 GDN intermediates were bit-identical. In the adaptive
arm, route-owner changes first occur at layers 2 and 3; the first per-layer
dispatch activation difference is at layer 4. At layer 26, GDN input `x` is
already different across all 2,560 values (relative L2 0.05743). Later captured
GDN fields also differ. This places the observed discrepancy upstream of the
layer-26 recurrent computation; it does not establish which earlier operation
or state transition first introduced it.

The adaptive initial/recovery state fingerprints differ in `gdn`, `tail`,
`pooled`, `pooled_full`, and `kv`, while the delayed fingerprints match. The
recovery token IDs match in both arms. Minimum host/admission availability was
14.25 GiB for adaptive and 14.36 GiB for delayed; both services passed the
28-GiB supervisor and all sampled cgroup `low`, `high`, `max`, `oom`, and
`oom_kill` event counters were zero. Clocks remained dynamic; energy was not
measured.

`campaign.json` records both arms, prompt hashes, binary and model identities,
token IDs, fingerprints and memory minima. Each GDN intermediate capture is
345,032 bytes; the raw SHA256 and per-field summaries are in
`adaptive-gdn-comparison.json` and `delayed-gdn-comparison.json`. The
layer-by-layer dispatch comparison is in `layer25-owner-comparison.json`.
These JSON files are generated by the sibling `compare_layer25_owner_positions.py`
and `compare_layer26_gdn_intermediates.py` tools. Raw service/supervisor traces
are under each arm's `result/` and `supervisor/` directories.

Reproduce the pair from the repository root with:

```sh
python3 bench/results/2026-10-20-phase5-coder-adaptive-all-layer-position-trace/run_pair.py \
  --run --continuations 0 --capture-moe-positions 520 \
  --capture-verify-gdn-layer 26 --verify-gdn-positions 520 \
  --output bench/results/2026-10-20-phase5-coder-adaptive-all-layer-position-trace/reproduction-position520
```
