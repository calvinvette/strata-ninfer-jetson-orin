# Q2_0 actual 32K prompt admission — Orin — 2026-10-11

This extends the Q2_0 configured-context measurements with actual 32,768-token
prompt ingestion. It ran on local `orin1` (Orin AGX, ARM64, CUDA 12.6) using the
native Q2_0 shards, the matching PLE pack and expert profile, a fixed 256-slot
expert cache, `--prefill 512`, `--spec 2`, `--prompt-cache 6`, and a 32,800-token
context reservation. One output token was requested. The current candidate
binary and all model/pack/profile identities are in `artifact-identities.json`;
full arguments, prompt hash, output ID and usage are in
`attempt-3/workload.json`. The exact prompt was generated by the retained
`runner.py` and validated at 32,768 tokens before engine launch.

The first two launches were rejected by Strata's request context validator
before prefill. Context reservations of 32,769 and 32,770 tokens were both too
small for the internal boundary accounting; these are test-setup validation
failures, not capacity or engine failures. Their logs and supervisor samples
are retained under `attempt-1/` and `attempt-2/` (including `engine.txt`). The 32,800-token attempt
passed validation and ingested all 32,768 tokens, as confirmed by both the
prompt trace and `prompt_read`. It emitted token ID 32. No prompt tokens were
reused. The configured reserve was sufficient for this one request.

Prompt processing took 187,923.9 ms and the one-token decode took 230.7 ms.
These are descriptive values from a single admission request, not a benchmark
or a quality comparison. Supervisor status was `pass`; minimum host
`MemAvailable` was 21,316,354,048 bytes (19.85 GiB), above the six-GiB floor.
Across 190 memory/clock samples, GPU rates ranged 306–1,300.5 MHz (median
1,122 MHz), EMC remained at 3,199 MHz, and sampled CPU rates ranged 729.6–2,201.6
MHz. Clocks were observed, not controlled. Energy was not measured; raw
tegrastats rails are retained.

The opt-in owner trace recorded 304 allocations and 303 frees. The session
requested peak was 992,360,448 bytes; prefill peaked at 350,079,744 bytes;
verifier at 45,837,056 bytes; pageable expert-stage host backing at 353,894,400
bytes; mapped verifier host staging at 495,480 bytes. Those owners returned to
zero requested live bytes. The 1,485,606,400-byte dense WeightTable arena
remained live at the end of the engine log, consistent with its process-lifetime
weight ownership; process termination is not represented as an owner free.
These are requested bytes at instrumented sites, not total physical use. Graph
pool/driver bytes and other uninstrumented allocations are not priced by this
trace. The six-GiB host `MemAvailable` measurement remains the physical-memory
authority; CUDA capacity is not added to host RAM.

This supplies an actual long-prompt admission point for Q2_0 at a 32K configured
context and fixed cache size. It does not establish 32K quality, repeatability,
concurrency, performance, a supported capacity limit, or graph-pool size.
Broader pressure and memory-attribution gates remain open; no default changed.
Models and generated packs remain under `/home/calvin/models/` and are not in
Git.
